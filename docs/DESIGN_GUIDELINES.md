# Phera Design Guidelines

These rules ensure visual consistency and a premium feel across the administrative dashboard and user-facing modals.

## 1. Modals & Popups

- **Background**: Always use white (`#ffffff`) by default.
- **Text Color**: Use dark/black font color (e.g., `#1a1a1a`) for all content.
- **Border Radius**: 24px (M3 Large).

## 2. Inputs & Forms

- **Focus State**: When an input is clicked into or highlighted, the border color MUST use the primary pink: `#DE3F5E`.
- **Text Color**: Input text, placeholder logic, and labels should always be dark/black by default.
- **Background**: Use a subtle light background (e.g., `#f8f9fa`) for the input area to differentiate from the white modal background.

## 3. General Typography

- **Default Font Color**: All text (headings, body, etc.) should be dark or black by default to ensure maximum readability against white backgrounds.
- **Primary Color**: `#DE3F5E` (Pink) is the primary accent color for active states, buttons, and focused elements.

## 4. Components

- **Buttons**: Rounded (100px or 24px radius), using Primary Pink (`#DE3F5E`) for primary actions.
- **Dialogs**: Clean, centered, and minimal with ample white space.
