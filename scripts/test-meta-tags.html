🧪 Testing Instructions

  1. Deploy your changes to production
  2. Test the link in WhatsApp:
    • Send the link to yourself or a friend
    • Check if the preview image appears
    • Verify the title and description are correct
  3. Use Facebook's Sharing Debugger: https://developers.facebook.com/tools/debug/
  4. Use LinkedIn's Post Inspector: https://www.linkedin.com/post-inspector/

⚠️ Important Notes

  • WhatsApp caches link previews aggressively. If you don't see changes immediately, try:
  • - Adding a query parameter to the URL (e.g., ?v=1)
  • - Waiting 24-48 hours for cache to clear
  • - Using Facebook's Sharing Debugger to force a refresh
